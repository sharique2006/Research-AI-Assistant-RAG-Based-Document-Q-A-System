# Research-AI-Assistant-RAG-Based-Document-Q-A-System
Built a Research AI Assistant using Streamlit, LangChain, Groq, OpenAI Embeddings, and FAISS.
Key Features:

📄 PDF document ingestion and text splitting

🔍 Semantic search using FAISS vector database

🤖 Context-aware answers using Retrieval-Augmented Generation (RAG)

⚡ Fast responses powered by Groq LLM

📖 Retrieved document passages for answer verification

🎨 Clean, interactive UI built with Streamlit

🛠️ Tech Stack: Python | Streamlit | LangChain | Groq | OpenAI Embeddings | FAISS | RAG

This project helped me explore document retrieval, vector databases, embeddings, and LLM-powered question answering.
